**Investment Research Assistant v1.0 - Project Origin**

**Creator**

Sean Mitchell

**Project Creation**

Investment Research Assistant v1.0 was independently conceived and initiated by Sean Mitchell on 13 July 2026.

The project was created as a personal software development project with the intention of creating a structured investment research assistant capable of supporting the collection, organisation and analysis of financial and non-financial information.

**Purpose**

The purpose of Investment Research Assistant is to assist with:

- The organisation of investment research information
- Financial statement analysis
- Company comparison
- Valuation modelling
- Investment research workflow management

The project is intended to support personal investing activities, professional development and future analytical workflows.

**Development Independence**

The project is independently developed by Sean Mitchell using personal resources.

Development is conducted using:

- Personal GitHub account
- Personal computing equipment
- Independently sourced learning materials
- Publicly available financial information

No employer resources, confidential information, proprietary systems or internal methodologies are used in the creation of this project.

**Motivation**

Investment Research Assistant was conceived as a tool to improve the consistency, structure and efficiency of investment research.

The project was also motivated by the recognition that complex analytical workflows require effective information management systems.

By externalising repetitive processes, calculations and information organisation, the application aims to allow greater focus on higher-value analytical judgement.

**Initial Project Status**

At the time of creation, the project consists of:

- Established GitHub repository
- Defined project objectives
- Planned software architecture
- Initial development roadmap

Software implementation has not yet commenced.
