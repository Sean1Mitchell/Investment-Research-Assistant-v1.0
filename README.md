# Investment Research Assistant v1.0

**Overview**

Investment Research Assistant v1.0 is an independently developed Python application designed to support structured investment research through the collection, organisation and analysis of publicly available financial and non-financial information.

The project aims to assist with company analysis, financial modelling, valuation assessment and research workflow management.

---

**Creator & Project Origin**

Created and developed by Sean Mitchell.

Investment Research Assistant was independently conceived and initiated as a personal software development project prior to employment with any investment organisation.

The project is developed using personal equipment, personal accounts and publicly available information.

No confidential information, proprietary systems or employer resources are used in the development of this project.

---

**Motivation**

Investment Research Assistant was created to improve the efficiency, consistency and structure of my investment research process.

The project was also motivated by the need to create external systems that support information organisation, working memory and repeatable analytical workflows.

Rather than replacing professional judgement, the purpose of the application is to reduce repetitive tasks and allow greater focus on analysis and decision-making.

---

**Design Principles**

The project follows several principles:

- Support analyst judgement rather than replace it.
- Maintain transparency in calculations and analysis.
- Use publicly available information.
- Create repeatable and consistent research workflows.
- Reduce unnecessary administrative workload.
